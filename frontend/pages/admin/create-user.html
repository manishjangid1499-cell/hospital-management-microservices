Create New User Account
Create accounts for staff members: Doctors, Receptionists, Pharmacists, Billing Officers, or Admins.
Note: Patients can self-register through the registration page.
A secure temporary password will be automatically generated by the system and emailed to the user's registered address. The user will be required to set a new permanent password upon their first login.
Role Descriptions
ADMIN Full system access. Can manage all users and view all data.
DOCTOR View appointments, create clinical records, write prescriptions.
RECEPTIONIST Register patients, manage appointments.
PHARMACIST View/dispense prescriptions, manage medication inventory.
BILLING_OFFICER Manage invoices and payments.
